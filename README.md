## 🛠️ نصب و تنظیم

### مرحله 1: نصب Python
```bash
# برای Linux/Mac
sudo apt-get install python3 python3-pip

# برای Windows
# از https://python.org دانلود کنید
```

### مرحله 2: دانلود فایل‌ها
```bash
# دانلود تمام فایل‌ها در یک پوشه
mkdir vpn_bot
cd vpn_bot
# کپی تمام فایل‌های Python را اینجا بگذارید
```

### مرحله 3: نصب وابستگی‌ها
```bash
pip install -r requirements.txt
```

### مرحله 4: تنظیم BOT TOKEN

#### روش 1: متغیر محیطی (توصیه‌شده)
```bash
# Linux/Mac
export BOT_TOKEN="YOUR_BOT_TOKEN_HERE"
export ADMIN_ID="YOUR_ADMIN_ID_HERE"

# Windows (Command Prompt)
set BOT_TOKEN=YOUR_BOT_TOKEN_HERE
set ADMIN_ID=YOUR_ADMIN_ID_HERE
```

#### روش 2: ویرایش فایل config.py
```python
BOT_TOKEN = "YOUR_BOT_TOKEN_HERE"
ADMIN_ID = 123456789  # شناسه عددی شما
```

### مرحله 5: دریافت Bot Token

1. در Telegram، @BotFather را جستجو کنید
2. دستور `/newbot` را ارسال کنید
3. نام بات را وارد کنید (مثل: VPNBot)
4. نام کاربری را وارد کنید (مثل: vpn_bot)
5. Token دریافت خواهید کرد

### مرحله 6: دریافت ADMIN ID

1. @userinfobot را در Telegram جستجو کنید
2. آن را شروع کنید
3. شناسه عددی خود را کپی کنید

### مرحله 7: تنظیم اطلاعات کارت

فایل `config.py` را باز کنید و بخش `CARD_RECEIVER` را تغییر دهید:

```python
CARD_RECEIVER = {
    "name": "نام شما",
    "card_number": "XXXX XXXX XXXX XXXX",
    "sheba": "IR...",
    "bank": "نام بانک"
}
```

## 📱 استفاده بات

### برای کاربران عادی:
```
/start              - شروع بات
💼 سرویس‌ها          - مشاهده سرویس‌ها
👤 حساب من          - حساب کاربری
📞 تماس             - تماس با پشتیبانی
📖 راهنما            - راهنمای استفاده
```

### برای مدیر:
```
/admin              - ورود به پنل مدیریتی
```

### دستورات پنل مدیریتی:
- 📊 **آمار** - مشاهده درآمد و آمار کاربران
- 👥 **کاربران** - مدیریت کاربران
- 💰 **پرداخت‌ها** - تایید پرداخت‌های در انتظار
- 📢 **پیام همگانی** - ارسال پیام به تمام کاربران
- ⚙️ **سرویس‌ها** - مدیریت سرویس‌ها

## 💾 ساختار Database

بات خودکار یک فایل `vpn_bot.db` (SQLite) می‌سازد.

### جداول:
- **users** - اطلاعات کاربران
- **services** - سرویس‌های موجود
- **payments** - درخواست‌های پرداخت
- **admin_logs** - لاگ فعالیت‌های ادمین

## 🎨 تنظیم سرویس‌ها

تمام سرویس‌ها در فایل `config.py` قابل‌تنظیم هستند:

```python
SERVICES = {
    "basic": {
        "name": "🔓 نامحدود پایه",
        "price": 35000,
        "description": "توضیح سرویس",
        "servers": ["کشور1", "کشور2"],
        "duration": 30
    },
    # ...
}
```

## ⚙️ تنظیمات اضافی

### پیام‌های سفارشی
فایل `config.py` را باز کنید و بخش `MESSAGES` را تغییر دهید.

### رنگ‌ها و ایموجی‌ها
بخش `EMOJIS` در `config.py` را ویرایش کنید.

## 🐛 رفع خرابی

### خطا: "Bot token not valid"
- ✅ Token را صحیح کپی کرده‌اید؟
- ✅ متغیر محیطی درست تنظیم شده؟

### خطا: "ADMIN_ID not set"
- ✅ ADMIN_ID خود را تنظیم کردید؟
- ✅ شناسه عددی است نه متن؟

### بات جواب نمی‌دهد
- ✅ Webhook صحیح تنظیم شده؟
- ✅ اینترنت متصل است؟

## 🔐 نکات امنیتی

1. **Token را محفوظ نگه دارید** - هرگز Token را عمومی نکنید
2. **متغیرهای محیطی استفاده کنید** - از config فایل به جای hardcode استفاده کنید
3. **ADMIN_ID را ثبت کنید** - فقط ادمین می‌تواند پنل را ببیند
4. **Database را بک‌آپ کنید** - به صورت منظم
